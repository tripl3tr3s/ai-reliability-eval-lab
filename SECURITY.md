# Security Policy

Report vulnerabilities privately through GitHub Security Advisories. Do not include credentials or real taxpayer data in a report.

Only the latest release is supported. The repository intentionally has no database, hosted API, authentication system, or persistent service. Live workflows use protected environments and never expose provider credentials to forked pull requests.

Synthetic benchmark transcripts are public. Secret-like fields are masked before optional telemetry export, but contributors must still inspect artifacts before publication.
